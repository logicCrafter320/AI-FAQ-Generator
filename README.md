## How To Run Locally

1. Clone the repo
git clone https://github.com/logicCrafter320/ai-faq-bot.git
cd ai-faq-bot

2. Install dependencies
npm install

3. Add your Groq API key
Create a .env file:
GROQ_API_KEY=your_key_here

Get free key at: console.groq.com

4. Run the app
npm run dev

5. Open browser
http://localhost:5000

## How To Use

Step 1: Paste your business description
"We are a fitness coaching business

Paste on your website before </body>
